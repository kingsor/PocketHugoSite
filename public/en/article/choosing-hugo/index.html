I chose Hugo for this blog

2025-08-13 Blogging 1 min read 155 words
Description “After using Jekyll, I switched to Hugo, and I'm really happy with it.”

For a while, I used Jekyll for my blog, which is originally supported by default on GitHub Pages . It’s a solid static site generator , but it’s complicated to test locally on Windows unless you use Docker .

So I looked for something else and eventually settled on Hugo , which is very user-friendly, written in Go , supports pages and posts written in Markdown , and is very fast at generating the site locally for testing before publishing.

It has excellent support on its website and on Stack Overflow , and offers numerous free themes to choose from if you’re unable or unwilling to create your own.

GitHub Pages supports publishing a site with Hugo , so it’s very convenient to write blog posts locally, test the results locally, make any necessary corrections, and—once you’re satisfied—commit and push to the relevant repository, then see your blog updated online within a few minutes.
